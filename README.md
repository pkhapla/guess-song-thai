# 🎵 ทายเพลงไทย

เกมทายเพลงไทยแบบ [songtrivia.io](https://songtrivia.io/) — ฟังตัวอย่างเพลงแล้วเลือกคำตอบจาก 4 ตัวเลือก ตอบเร็วยิ่งได้คะแนนเยอะ

- 3 โหมด: ทายชื่อเพลง / ทายศิลปิน / ต่อเนื้อเพลง
- 7 หมวด: ฮิตติดชาร์ต, ป๊อปไทย, ร็อกไทย, T-Pop, อินดี้, ยุค 90s–2000s, ลูกทุ่ง & หมอลำ
- เลือกศิลปินเองได้ (คั่นหลายคนด้วย `,`)
- 👥 เล่นกับเพื่อน: สร้างห้อง ส่งลิงก์ ทุกคนฟังเพลงเดียวกันพร้อมกัน มีกระดานคะแนนสดและสรุปอันดับตอนจบ
- ตัวอย่างเพลง 30 วินาทีจาก iTunes Search API (ร้านค้าประเทศไทย) + Deezer API ไม่ต้องมี API key
  - Deezer ช่วยเติมเพลงที่ iTunes ไม่มี และบอกว่าเพลงไหนฮิต (เพลงฮิตจะถูกสุ่มเป็นโจทย์ก่อน)
  - Deezer ไม่เปิด CORS เลยเรียกแบบ JSONP และลิงก์ตัวอย่างเพลงหมดอายุราว 15 นาที (แคชไว้ไม่เกินนั้น)

## โหมดต่อเนื้อเพลง

เห็นเนื้อเพลงท่อนหนึ่ง แข่งกันพิมพ์ท่อนต่อไปให้ถูกทุกคำ คนแรกที่ถูกครบได้ 1 คะแนน
- คำที่ใครพิมพ์ถูกจะเปิดให้ทุกคนเห็นตามตำแหน่ง
- ตัวช่วย: เฉลย 1 คำ, เฉลยชื่อเพลงและนักร้อง (โหวตถึงครึ่งหนึ่งแล้วใช้ทันที), ยอมแพ้ (ต้องกดครบทุกคน)
- โฮสต์มีปุ่มข้ามข้อ
- เนื้อเพลงจาก [LRCLIB](https://lrclib.net) (ฟรี ไม่ต้องมี key) เพลงไทยใน LRCLIB มีไม่ครบ เลยสร้างรายการเพลงที่มีเนื้อไว้ล่วงหน้าใน `lyrics-index.js` (เก็บแค่ id ตอนเล่นดึงเนื้อสด)

แก้ศิลปินใน `categories.js` แล้วให้สร้าง index ใหม่ (ใช้เวลานานเพราะ LRCLIB จำกัดความถี่ ผลค้นแคชไว้ใน `tools/.lyrics-cache.json`):

```bash
node tools/build-lyrics-index.mjs            # ทุกศิลปิน
node tools/build-lyrics-index.mjs Bodyslam   # เฉพาะศิลปินที่ชื่อมีคำนี้
```

ศิลปินที่พิมพ์เองตอนเล่นจะค้นเนื้อสดจาก LRCLIB (ช้ากว่าและอาจหาไม่ครบ)

## รันในเครื่อง

```bash
python3 -m http.server 8000
# เปิด http://localhost:8000
```

## ตั้งค่าโหมดเล่นกับเพื่อน (Supabase)

ใช้แค่ Supabase Realtime (Broadcast + Presence) ไม่ต้องสร้างตาราง ไม่ต้องมีเซิร์ฟเวอร์
1. สมัคร/สร้างโปรเจกต์ที่ [supabase.com](https://supabase.com) (ฟรี)
2. Project Settings → API → คัดลอก **Project URL** และ **anon public key**
3. ใส่ใน `config.js` แล้ว push — anon key เปิดเผยได้ ออกแบบมาให้อยู่ฝั่งเว็บ

> โปรเจกต์ Supabase ฟรีจะถูก pause ถ้าไม่มีการใช้งาน 1 สัปดาห์ (โหมดเล่นคนเดียวยังใช้ได้ปกติ) กด Restore ใน dashboard เพื่อเปิดใหม่

โฮสต์เป็นคนดึงเพลงจาก iTunes และสั่งเริ่ม/เฉลยแต่ละข้อ ทุกคนในห้องได้โจทย์ชุดเดียวกัน

## เพิ่ม/แก้ศิลปิน

แก้ใน `categories.js` — ใช้ชื่อศิลปินตามที่ iTunes ใช้ (ส่วนใหญ่เป็นอักษรอังกฤษ เช่น `Tai Orathai` ไม่ใช่ `ต่าย อรทัย`)
ถ้าใน Deezer ใช้ชื่อภาษาไทย ให้ใส่ชื่อสำรองหลัง `|` เช่น `"Tai Orathai|ต่าย อรทัย"`

## Deploy บน Render

เป็น Static Site — มี `render.yaml` ให้แล้ว
1. Render Dashboard → **New → Blueprint** → เลือก repo นี้ → Apply
   (หรือ **New → Static Site**, Build Command เว้นว่าง, Publish Directory `.`)
